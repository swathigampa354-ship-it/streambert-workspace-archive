# streambert-workspace-archive (workspace-archive branch)

Full archival snapshot of the Streambert APK-build workspace taken 2026-09-25.
Two branches in this repo:
- `main` — canonical Streambert Android app source with full git history
  (== swathigampa354-ship-it/streambert @ 7473996, the EAS-green APK build state).
- `workspace-archive` — THIS branch: every workspace artifact.

## Contents
- `streambert-app-source/` — byte-exact checkout of `main` @ 7473996 (EAS build 099ef266 FINISHED state)
- `streambert-build-worktree/` — raw local working copy at archive time (see SNAPSHOT_NOTES.md inside)
- `streambert-fork-stale/` — stale/corrupt earlier working copy (kept for audit only; DO NOT build from it)
- `expo-app-git-backup/` — internal git history of the old nested expo-app repo (reference)
- `backups/` — git bundles: backup-outer-68833b5.bundle, backup-expo-app-22d3578.bundle,
  backup-final-67227f9.bundle (SPLIT: part-aa + part-ab; restore:
  `cat backups/backup-final-67227f9.bundle.part-* > backup-final-67227f9.bundle`)
- `Streambert-Android.apk` — the shipped APK (76,274,985 B; SHA-256
  9e1749f8295512f70d4741c87988190dea358d5ecf60327371775e656a111f8d; also live as
  GitHub Release asset on the swathigampa354-ship-it/streambert repo, tag v2.6.0-android)
- `ISSUES_LOG.md` — complete log of all 26 issues (fixed + still-open)
- `streambert_complete_chat_history.txt` — full chat-history archive export
- `scratch/` — working drafts of the export
- (node_modules / android build dirs intentionally absent — regenerated by
  `npm ci` (root) + `npm install` (expo-app) + `npx expo prebuild`; they were
  sandbox-evicted and are 100% reproducible from package-lock manifests.)

## Security note
This repo is PRIVATE because the chat-history file preserves token strings that
were pasted in chat. The tokens are documented as compromised and must be revoked
in GitHub/expo.dev settings. Do NOT make this repo public until they are.
